# bountyguard

Zero-dependency Rust library & CLI to verify real open-source bounty escrows (Algora, BountyHub, Opire) and audit untrusted repositories for supply-chain honeypot traps (`build.rs`, `package.json`, `Makefile`, CI workflows) before running tests.

## Usage
```bash
bountyguard scan-dir ./cloned-repo
```
